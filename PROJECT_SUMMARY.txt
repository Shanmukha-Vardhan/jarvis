       "todayClasses": [ ... ],
       "deadlines": { "today": [ ... ], "upcoming": [ ... ] },
       "attendance": { ... },

2. Fast Plain-Text Audio Briefing (For Siri & Apple Shortcuts):
   GET /api/daily-briefing?format=text
   Description:
     Returns ONLY the clean plain-text spoken briefing (text/plain).
     Zero JSON parsing needed in Apple Shortcuts. Perfect for instant "Speak Text".

3. Two-Way Voice Commands ("Hey Siri, JARVIS"):
   POST /api/voice-command
   Headers: Content-Type: application/json
   Request Body:
     { "text": "tomorrow at 12 i should submit ASTMA lab assignment" }
   Response:
     {
       "action": "ADD_TASK" | "CHECK_SCHEDULE" | "CHECK_BIKE" | "CHECK_ATTENDANCE" | "CHAT",
       "reply": "Conversational reply spoken by Siri",
       "taskData": { ... }
     }

4. Tasks & Natural Language Task Parser:
   GET /api/tasks
     Returns all active and completed tasks from Firebase Firestore.
   POST /api/tasks
     Accepts either natural language prompt:
       { "prompt": "Wednesday 10am project review with professor" }
     Or manual task parameters:
       { "title": "Project Review", "course": "Project Evaluation", "dueDate": "2026-09-30T10:00", "priority": "high" }
   PATCH /api/tasks
     Update task completion status: { "id": "...", "completed": true }
   DELETE /api/tasks?id=...
     Permanently removes a task.

3. KEY LOGIC & INTELLIGENCE ENGINES BUILT
--------------------------------------------------------------------------------

A. Gen-Z Persona & Spoken Briefing Engine (src/lib/gemini.ts):
   - Zero robotic butler talk ("Boss", "Rise and shine", "I give you the green light").
   - Pure casual friend tone ("Morning bro", "Weather's pretty chill", "Real talk",
     "down bad at 68.8%", "don't even think about bunking that 8 AM", "lock in").
   - Summarizes classes naturally: never reads out 6 robotic start/end timestamps.
   - Kept strictly under 120 words (under 50 seconds when spoken aloud).
   - Sanitized spoken text: no quote marks, no escaped characters, no asterisks.

B. Smart Attendance Alerting Rule:
   - Overall attendance is 88.8% with 47 safe bunks.
   - BUT Financial Management (19EID401) is sitting in the danger zone at 68.8%
     (< 75% cutoff, needing 8 consecutive attendances).
   - The briefing specifically warns Shanmukha not to bunk his 8 AM Financial
     Management class.
   - If all subjects are healthy (>= 75%), attendance is omitted from the spoken briefing.

C. Deterministic IST Timezone & Date Parser:
   - Built in src/lib/gemini.ts with getNowIST() and parseTaskLocally().
   - Resolves all dates in Asia/Kolkata (UTC+5:30) wall-clock time.
   - Fixed bug where "tomorrow at 12" became 6:30 AM (UTC offset error): now strictly
     evaluates to 12:00 PM noon.
   - Fixed bug where "Wednesday 10am" became Tuesday noon: now maps exact calendar
     dates (e.g. 2026-09-30T10:00).

D. Bike & Commute Decision Engine (src/lib/services.ts):
   - Commute: 40-minute ride from Sai Nagar, Gopalapatnam to GITAM University Rushikonda.
   - Evaluates real-time Open-Meteo ECMWF data.
   - Commute rule: Take the bike if rain risk < 60% and 0.0 mm rainfall.
   - Skip bike only if rain probability >= 60% or heavy precipitation.

E. News Filter & Relevance Scorer (src/lib/services.ts):
   - Queries GNews technology headlines and scores them against high-priority keywords
     (AI, Apple, LLMs, OpenAI, software engineering, robotics, developer tools).
   - Filters out irrelevant clickbait (sneaker colorways, beer ads, sports gossip).
   - Returns top 1-3 high-relevance articles; includes single top headline in briefing.

F. Resilient Gemini Multi-Model Failover:
   - Primary model: gemini-3.1-flash-lite (fast sub-2s responses, healthy quota).
   - Automatic fallback to gemini-flash-latest, gemini-3.8-flash, gemini-3.5-flash-lite.
   - Built-in Gen-Z programmatic fallback builder (buildGenZBriefingFallback) ensures
     zero downtime or robotic output even during Google API demand spikes.
